# 携程旅行网 - 路由导航与页面跳转完整说明文档

## 文档说明
本文档用于AI开发工作流的最后检查阶段，确保所有页面路由跳转逻辑完整实现。文档包含：
- 所有页面路由定义
- 页面间跳转逻辑
- 登录状态对路由的影响


---

## 1. 核心页面清单

前端和后端初始化时，默认状态为未登录，端口对应的直接首页应为首页(未登录版)。

### 1.1 公共页面

| 页面名称 | 说明 | 访问权限 |
|---------|------|---------|
| 首页(未登录版) | 网站主页，包含搜索入口 | 未登录用户 |
| 首页(已登录版) | 网站主页，包含搜索入口 | 已登录用户 |
| 登录页 | 用户登录（账号密码/验证码） | 未登录用户 |
| 注册页 | 用户注册（手机验证码） | 未登录用户 |

### 1.2 机票相关页面

| 页面名称 | 说明 | 访问权限 |
|---------|------|---------|
| 航班搜索结果页 | 展示符合条件的航班列表 | 需要登录 |
| 订票页-乘机人信息 | 填写乘机人和联系人信息 | 需要登录 |
| 订票页-增值服务 | 选择增值服务 | 需要登录 |
| 支付页 | 订单支付（携带订单ID参数） | 需要登录 |
| 订单完成页 | 出票成功确认 | 需要登录 |

### 1.3 个人中心页面

| 页面名称 | 说明 | 访问权限 |
|---------|------|---------|
| 个人信息设置页 | 查看和编辑个人信息 | 需要登录 |
| 常用旅客信息页 | 管理常用旅客信息 | 需要登录 |
| 我的订单列表页 | 查看所有订单 | 需要登录 |
| 订单详情页 | 查看单个订单详情（携带订单ID参数） | 需要登录 |

## 2. 详细页面跳转逻辑

### 2.1 首页

#### 2.1.1 顶部导航栏跳转

**未登录状态：**
- 点击"登录"按钮 → 跳转到登录页
- 点击"注册"按钮 → 跳转到注册页

**已登录状态：**
- 显示用户名入口，不显示"登录"和"注册"按钮
- 点击用户名 →  跳转到个人信息设置页

#### 2.1.2 搜索功能跳转

**已登录状态：**
- 用户填写完整且合法的搜索条件（出发地、目的地、出发日期）
- 点击"搜索"按钮 → 跳转到航班搜索结果页（携带搜索参数）

**未登录状态：**
- 用户填写完整且合法的搜索条件
- 点击"搜索"按钮 → **跳转到登录页**
- 登录成功后 → **自动携带原搜索条件跳转到航班搜索结果页**

---

### 2.2 登录页

#### 2.2.1 页面内导航

- 点击"免费注册"链接 → 跳转到注册页
- 在"账号密码登录"和"验证码登录"之间切换 → 页面内Tab切换，不跳转

#### 2.2.2 登录成功后跳转

**场景1：直接访问登录页**
- 登录成功 → 跳转到首页

**场景2：从其他页面跳转而来（带returnUrl）**
- 例如：未登录时点击搜索 → 登录页
- 登录成功 → **跳转回原页面**（如航班搜索结果页）

**场景3：从订票流程跳转而来**
- 未登录时点击"预订"按钮 → 登录页
- 登录成功 → **跳转回航班搜索结果页或继续预订流程**

#### 2.2.3 登录失败

- 账号或密码错误 → 页面停留在登录页，显示错误提示
- 验证码错误 → 页面停留在登录页，显示错误提示
- 未勾选服务协议 → 页面停留在登录页，显示提示

---

### 2.3 注册页

#### 2.3.1 注册流程跳转

**步骤1：验证手机号**
- 点击"不同意"按钮（用户协议弹窗） → 跳转到首页
- 点击"同意并继续"按钮 → 页面停留在注册页，进入步骤1
- 点击"下一步，设置密码"按钮（验证成功） → 进入步骤2

**步骤2：设置密码**
- 点击"<返回上一步"按钮 → 返回到步骤1
- 点击"完成"按钮（注册成功） → 跳转到登录页

#### 2.3.2 注册失败

- 手机号格式错误 → 页面停留在注册页
- 验证码错误 → 页面停留在注册页
- 密码格式不符合要求 → 页面停留在注册页
- 两次密码不一致 → 页面停留在注册页

---

### 2.4 航班搜索结果页

#### 2.4.1 进入方式

- 从首页搜索 → 航班搜索结果页（携带搜索参数：出发地、目的地、日期）
- 刷新或分享带查询参数的URL → 保留筛选状态重新加载

#### 2.4.2 登录状态检查

**未登录状态：**
- 访问搜索结果页 → **跳转到登录页**
- 登录成功后 → **返回航班搜索结果页（保留搜索条件）**

**已登录状态：**
- 正常展示航班列表

#### 2.4.3 页面内操作跳转

**选择航班套餐：**
- 点击航班卡片的"订票"按钮 → 展开套餐面板（页面内操作）
- 点击某套餐的"预订"按钮 → 跳转到订票页-乘机人信息（保存航班和套餐信息到会话）

**修改搜索条件：**
- 修改出发地/目的地/日期后点击"搜索" → 刷新当前航班搜索结果页（更新URL参数）
- 使用快捷筛选/排序 → 刷新当前页面列表（不跳转）

---

### 2.5 订票页-乘机人信息

#### 2.5.1 进入方式

- 从航班搜索结果页选择套餐后点击"预订" → 订票页-乘机人信息（携带航班和套餐参数）

#### 2.5.2 登录状态检查

**未登录状态：**
- 访问订票页 → **跳转到登录页**
- 登录成功后 → **返回订票页-乘机人信息（保留航班和套餐信息）**

**已登录状态：**
- 正常展示订票表单

#### 2.5.3 页面操作跳转

- 点击"下一步"按钮（信息填写完整且合法） → 跳转到订票页-增值服务
- 信息填写不完整或不合法 → 页面停留在订票页-乘机人信息，显示错误提示

#### 2.5.4 使用常用旅客信息

- 点击"常用旅客"复选框 → 自动填充信息（页面内操作）
- 点击"新增乘机人" → 新增输入卡片（页面内操作）
- 点击"删除" → 删除信息卡片（页面内操作）

---

### 2.6 订票页-增值服务

#### 2.6.1 进入方式

- 从订票页-乘机人信息点击"下一步" → 订票页-增值服务

#### 2.6.2 页面操作跳转

- 点击"下一步"按钮 → 系统生成订单号，跳转到支付页（携带订单ID）

---

### 2.7 支付页

#### 2.7.1 进入方式

- 从订票页-增值服务点击"下一步" → 支付页（携带订单ID）

#### 2.7.2 页面操作跳转

**支付成功：**
- 点击"支付"按钮（支付完成） → 跳转到订单完成页

---

### 2.8 订单完成页

#### 2.8.1 进入方式

- 从支付页支付成功后 → 订单完成页

#### 2.8.2 页面操作跳转

- 点击"返回首页"按钮 → 跳转到首页
- 订单状态更新为待出行

---

### 2.9 个人信息设置页

#### 2.9.1 进入方式

- 从首页顶部栏点击用户名→ 个人信息设置页

#### 2.9.2 登录状态检查

**未登录状态：**
- 访问个人信息页 → **跳转到登录页**
- 登录成功后 → **返回个人信息设置页**

#### 2.9.3 导航栏跳转

- 点击导航栏"常用信息" → 跳转到常用旅客信息页
- 点击导航栏"订单管理" → 跳转到我的订单列表页

---

### 2.10 常用旅客信息页

#### 2.10.1 进入方式

- 从个人中心导航栏点击"常用信息" → 常用旅客信息页

#### 2.10.2 登录状态检查

**未登录状态：**
- 访问常用旅客信息页 → **跳转到登录页**
- 登录成功后 → **返回常用旅客信息页**

#### 2.10.3 页面操作

- 点击"新增"按钮 → 跳转到常用旅客信息编辑页（或弹窗）
- 点击"编辑"按钮 → 跳转到常用旅客信息编辑页（或弹窗）
- 点击"保存"按钮（信息合法） → 保存成功，返回常用旅客信息页
- 点击"保存"按钮（信息不合法） → 页面停留在编辑页，显示错误提示
- 点击"删除"按钮 → 删除确认后，页面停留在常用旅客信息页，刷新列表

#### 2.10.4 导航栏跳转

- 点击导航栏"个人信息" → 跳转到个人信息设置页
- 点击导航栏"订单管理" → 跳转到我的订单列表页

---

### 2.11 我的订单列表页

#### 2.11.1 进入方式

- 从首页顶部导航栏点击"我的订单" → 我的订单列表页
- 从个人中心导航栏点击"订单管理" → 我的订单列表页

#### 2.11.2 登录状态检查

**未登录状态：**
- 访问订单列表页 → **跳转到登录页**
- 登录成功后 → **返回我的订单列表页**

#### 2.11.3 页面操作跳转

**查看订单详情：**
- 点击订单卡片 → 跳转到订单详情页（携带订单ID）

**去支付（待支付订单）：**
- 点击订单卡片的"去支付"按钮 → 跳转到支付页（携带订单ID）

**标签切换：**
- 点击"全部订单"/"未出行"/"待支付"/"已完成"标签 → 页面停留在我的订单列表页，刷新列表

**类型筛选：**
- 选择订单类型下拉框 → 页面停留在我的订单列表页，刷新列表

---

### 2.12 订单详情页

#### 2.12.1 进入方式

- 从我的订单列表页点击订单卡片 → 订单详情页（携带订单ID）

#### 2.12.2 登录状态检查

**未登录状态：**
- 访问订单详情页 → **跳转到登录页**
- 登录成功后 → **返回订单详情页（保留订单ID）**

#### 2.12.3 页面操作跳转

**待支付订单：**
- 点击"去支付"按钮 → 跳转到支付页（携带订单ID）

**待出行订单：**
- 点击"取消订单"按钮 → 弹出确认弹窗
  - 确认取消 → 订单状态更新为"已取消"，页面停留在订单详情页，刷新显示
  - 取消操作 → 页面停留在订单详情页

**已取消订单：**
- 点击"重新下单"按钮 → 跳转到首页或航班搜索结果页（携带原订单搜索条件）
